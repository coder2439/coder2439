Full-stack engineer. I take a product from the interface through the API, the database, and deployment.

The front of that work is TypeScript: React and Next.js on the web, React Native and Flutter on mobile, and Kotlin on Android. Behind it I build Node.js and Python services, store data in PostgreSQL, Supabase, and Firebase, and ship on Vercel and AWS.
